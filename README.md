# Quando stacco

Web app per calcolare l'orario di uscita dal lavoro: 8 ore + pausa pranzo (minimo 30 minuti).
Gestisce anche i giorni di smart working (10 al mese) e lo zainetto dei minuti extra.

Online: https://dtinti98.github.io/orario-uscita/

I dati restano salvati solo sul dispositivo (localStorage). Dal menu si può esportare e reimportare un backup CSV.
